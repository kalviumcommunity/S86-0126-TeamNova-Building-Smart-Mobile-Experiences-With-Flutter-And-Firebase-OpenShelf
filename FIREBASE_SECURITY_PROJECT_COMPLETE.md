## 💼 Integration Points

### With Cloud Functions
```
Firebase Cloud Messaging → User tokens stored in Firestore
→ Rules control who can read device tokens
→ Cloud Functions use tokens for notifications
```

### With Flutter App
```
Flutter App → AuthService (sign up/in/out)
→ User document in Firestore
→ Rules control data access
→ App reads profile with rules-protected access
```

### Complete Architecture
```
Firebase Console
├── Authentication (email/password)
├── Firestore
│   ├── Security Rules
│   └── User Documents
└── Project Settings

Flutter App
├── firebase_auth package
├── cloud_firestore package
├── AuthService (singleton)
└── UI Screens (sign-up/in)
```
