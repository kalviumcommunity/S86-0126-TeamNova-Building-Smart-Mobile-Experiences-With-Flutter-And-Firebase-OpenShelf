## 🔍 Quick Reference

### Key Concepts at a Glance

```
BottomNavigationBar
├─ Simple, native widget
├─ Works on all devices
├─ Best for 3-5 tabs
└─ setState or Riverpod

State Preservation
├─ IndexedStack (best for most)
├─ PageView (if swipe needed)
├─ KeepAlive (selective)
└─ Riverpod (complex apps)

Responsive Design
├─ Mobile: BottomNavigationBar
├─ Tablet: NavigationRail
└─ Switch at 600dp breakpoint

Testing Strategy
├─ Unit tests: 80%+ coverage
├─ Widget tests: 85%+ coverage
├─ Integration tests: 75%+ coverage
└─ Total: 90%+ target
```
